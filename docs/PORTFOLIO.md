# AIDUS — Portfolio Case Study

## Overview

AIDUS is a personal product and brand concept for an AI automation company. The experience is designed around a simple product idea: business owners should be able to understand where operational friction and missed opportunities occur, then use intelligent automation to handle repetitive work.

## Design objective

Create a premium, modern interface that communicates an advanced AI product without overwhelming the user with technical complexity.

## Design principles

1. **Clarity first** — establish a strong hierarchy so the visitor understands the value proposition quickly.
2. **Editorial visual language** — large typography, generous spacing, restrained color, and cinematic media create a distinctive identity.
3. **Progressive disclosure** — detailed information is introduced through dedicated sections and views rather than presenting everything at once.
4. **Consistency** — repeated UI patterns are implemented as reusable React components.
5. **Conversion with context** — calls to action lead into pricing, comparison, scheduling, and confirmation flows rather than isolated buttons.

## Experience structure

The current application includes a landing experience followed by feature, brand/social-proof, testimonial, integration, pricing, CTA, comparison, scheduling, and thank-you experiences. Navigation and view state are handled from the application shell.

## Interaction and implementation

The interface uses React components and TypeScript. Motion is used for entrance transitions and interactive feedback. Responsive classes support desktop and mobile layouts. The application also includes a dark/light mode system and reusable sections for repeated patterns.

## Visual direction

The design combines a near-black editorial foundation with high-contrast typography and subtle motion. The hero uses large display typography and video to create an immediate visual statement. Secondary sections become progressively more information-dense while retaining generous spacing and clear grouping.

## Reflection

This project was created as a personal design and implementation exercise. The focus was on translating product positioning into a coherent interface, designing the interaction structure, and building the experience as a maintainable component system rather than a collection of manually positioned screens.
