# AIDUS — AI Business Automation

AIDUS is a product and brand concept focused on AI-powered business automation. This repository contains the current React/Vite implementation of the AIDUS website and interactive experience.

## What this project demonstrates

- Product and web interface design
- Responsive React implementation
- Component-based UI architecture
- Interactive navigation and multi-step views
- Motion and micro-interactions
- Dark/light visual modes
- Pricing, comparison, scheduling, and thank-you flows
- AI/automation-oriented product positioning

## Core stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Lucide React
- HLS.js
- Google GenAI SDK
- Supabase client

## Project structure

- `src/App.tsx` — application shell and navigation between views
- `src/components/` — reusable UI sections and product flows
- `index.html` — application entry point
- `package.json` — scripts and dependencies

## Local development

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Design direction

The AIDUS experience uses a dark, editorial visual language with large typography, strong hierarchy, restrained motion, and conversion-focused interaction patterns. The goal is to make a complex AI automation offering feel clear, premium, and approachable.

## Portfolio context

This is a personal project and work sample created to demonstrate product thinking, interface design, interaction design, and front-end implementation.
